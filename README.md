# کتابخانه من 📚

کتابخانه شخصی PDF برای اندروید: قفسه‌ای با جلد واقعی هر کتاب، افزودن PDF در هر زمان، و مطالعه کاملاً آفلاین.

- Kotlin + Jetpack Compose (Material 3)، معماری MVVM + Repository، Room، DataStore، Coroutines/Flow
- نمایش PDF با `PdfRenderer` داخلی اندروید (صفحه‌به‌صفحه، کش bitmap محدود)
- بدون مجوز اینترنت و بدون مجوز ذخیره‌سازی (انتخاب فایل با Storage Access Framework)
- حداقل Android 7.0 (API 24)، `targetSdk 35`
- رابط فارسی با RTL کامل و فونت وزیرمتن

> ⚠️ وضعیت صادقانه: این پروژه نوشته شده ولی در محیط تولیدش **Build واقعی انجام نشده** (Android SDK و دسترسی به GitHub نبود). اولین اجرای Workflow ممکن است به یک یا چند رفع خطای کوچک نیاز داشته باشد. بخش «وضعیت و محدودیت‌ها» را ببینید.

## ۱) بارگذاری در GitHub (مرحله‌به‌مرحله، برای مبتدی)

1. در [github.com](https://github.com) وارد شوید و روی **New repository** بزنید. نام مثلاً `MyLibrary`؛ **Private** یا Public فرقی ندارد. گزینه‌های README/.gitignore را **تیک نزنید**.
2. پوشه این پروژه را روی کامپیوتر باز کنید و در ترمینال بزنید:
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/MyLibrary.git
   git push -u origin main
   ```
   (به‌جای `USERNAME` نام کاربری خودتان را بگذارید.)
   اگر Git ندارید: در صفحه مخزن، **Add file ← Upload files** و همه فایل‌ها و پوشه‌ها (از جمله پوشه مخفی `.github`) را بکشید و رها کنید.
3. بعد از push، Workflow به‌طور خودکار شروع می‌شود.

## ۲) دریافت APK از بخش Actions

1. در صفحه مخزن روی تب **Actions** بزنید.
2. آخرین اجرای **Build APK** را باز کنید. اگر دایره زرد است صبر کنید (حدود ۵ تا ۱۰ دقیقه)؛ تیک سبز یعنی موفق.
3. پایین صفحه، بخش **Artifacts**، فایل **MyLibrary-APK** را دانلود کنید (zip است؛ از حالت فشرده خارج کنید).
4. داخلش دو فایل است: `MyLibrary-release.apk` (امضاشده، برای استفاده روزمره) و `MyLibrary-debug.apk`.
5. اگر قرمز شد: روی مرحله قرمز کلیک کنید، متن خطا را کپی کنید و برای رفع به من/هر دستیار برنامه‌نویسی بدهید.

## ۳) دریافت APK از بخش Releases (با tag)

1. در ترمینال:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
2. بعد از اتمام Workflow، در صفحه مخزن سمت راست روی **Releases** بزنید؛ APKها آنجا هستند و لینک مستقیم دانلود دارند.

## ۴) نصب روی گوشی

1. فایل `MyLibrary-release.apk` را به گوشی منتقل کنید (یا از مرورگر گوشی دانلود کنید).
2. با لمس فایل، اگر اندروید خواست اجازه **نصب از منبع ناشناس** را برای همان برنامه (مرورگر/مدیر فایل) فعال کنید.
3. نصب کنید و «کتابخانه من» را باز کنید.

## ۵) کار با اپ

- **افزودن PDF:** دکمه شناور «افزودن PDF» ← یک یا چند فایل را انتخاب کنید. پیشرفت ورود نمایش داده می‌شود، فایل‌های تکراری تشخیص داده می‌شوند و خراب/رمزدار با پیام فارسی گزارش می‌شوند. از هر فایل یک نسخه در حافظه خصوصی اپ ذخیره می‌شود.
- **باز کردن PDF از برنامه‌های دیگر:** روی یک PDF در مدیر فایل/پیام‌رسان ← «کتابخانه من»؛ اپ پیشنهاد افزودن می‌دهد.
- **خواندن:** اسکرول عمودی، زوم با دو انگشت (۱× تا ۴×) یا دوبار لمس، لمس نشانگر «صفحه X از Y» برای پرش به صفحه، آیکن نشانک، آیکن ماه/خورشید برای حالت شب. آخرین صفحه خودکار ذخیره می‌شود.
- **مدیریت کتاب:** لمس طولانی روی جلد (یا ⋮ در حالت لیست): علاقه‌مندی، تغییر نام و دسته، اشتراک‌گذاری، اطلاعات فایل، حذف (با امکان بازگردانی بلافاصله).
- **پشتیبان:** تنظیمات ← پشتیبان‌گیری (فقط فهرست یا همراه فایل‌ها) و بازیابی.

## ۶) ساخت دوباره APK

- هر `push` به `main` یا اجرای دستی (**Actions ← Build APK ← Run workflow**) یک APK تازه می‌سازد.
- ساخت محلی (نیازمند JDK 17 و Android SDK):
  ```bash
  ./gradlew assembleRelease   # خروجی: app/build/outputs/apk/release/
  ./gradlew testDebugUnitTest # تست‌های واحد
  ```
  اگر کلید release تعریف نشده باشد، نسخه release با کلید debug امضا می‌شود (فقط برای تست).
- برای ساخت محلی، دو فایل فونت `Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf` را در `app/src/main/assets/fonts/` بگذارید (Workflow خودش دانلود می‌کند؛ بدون فونت، اپ با فونت سیستم اجرا می‌شود).

### امضای پایدار (مهم برای به‌روزرسانی)

اگر Secrets تنظیم نکنید، Workflow در هر اجرا یک کلید **موقت جدید** می‌سازد؛ در نتیجه APKِ اجرای بعدی روی نسخه نصب‌شده قبلی «نصب به‌روزرسانی» نمی‌شود (باید اول پاک کنید). برای کلید ثابت:

1. یک بار کلید بسازید:
   ```bash
   keytool -genkeypair -v -keystore release.jks -alias mylibrary -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 release.jks   # خروجی را کپی کنید
   ```
2. در مخزن: **Settings ← Secrets and variables ← Actions ← New repository secret** و این‌ها را بسازید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.
3. فایل `release.jks` را **هرگز** در مخزن commit نکنید (در `.gitignore` هست) و از آن یک نسخه پشتیبان نگه دارید.

## وضعیت و محدودیت‌ها (بدون ادعای اضافه)

**انجام‌شده در کد:** همه امکانات ضروری (۱ تا ۹ در شرح پروژه) و تکمیلی (علاقه‌مندی/دسته، نشانک، حالت شب و تم، اطلاعات فایل، پشتیبان‌گیری/بازیابی، انیمیشن و حالت خالی، صفحه خوشامد).

**تست‌نشده / نامعلوم:**
- پروژه هنوز Build نشده و روی هیچ دستگاه/شبیه‌ساز اجرا نشده است. تست‌های واحد (`LibraryLogicTest`, `ImportLogicTest`) نوشته شده ولی اجرا نشده‌اند.
- تست دستی (PDF حجیم، خراب، چرخش، حالت شب) انجام نشده است.
- نسخه‌های وابستگی (AGP 8.7.3، Kotlin 2.0.21، Compose BOM 2024.12.01) و `targetSdk 35` بر اساس دانش من انتخاب شده‌اند و ممکن است از «آخرین نسخه» جدیدتر باشند؛ در صورت نیاز در `build.gradle.kts` به‌روز کنید.
- دانلود فونت وزیرمتن در Workflow از GitHub انجام می‌شود؛ اگر آدرس تغییر کرده باشد، فقط هشدار می‌دهد و اپ با فونت سیستم ساخته می‌شود.

**محدودیت‌های شناخته‌شده:**
- **PDF رمزدار:** `PdfRenderer` اندروید از آن پشتیبانی نمی‌کند؛ اپ پیام فارسی می‌دهد و فایل اضافه نمی‌شود.
- حداکثر حجم هر فایل ۵۰۰ مگابایت. برای کتاب‌های بسیار پرصفحه، محاسبه اندازه صفحه‌ها قبل از نمایش چند ثانیه صفحه «آماده‌سازی» نشان می‌دهد.
- زوم تا ۴× است ولی کیفیت رندر تا ۳× پیکسل‌دار می‌شود (پس از آن کمی نرم دیده می‌شود). زوم حول مرکز صفحه است، نه نقطه لمس.
- پشتیبان «فقط فهرست» فقط روی کتاب‌هایی اعمال می‌شود که همان فایل (با همان محتوا) در اپ باشد.
- در حالت باز کردن PDF از برنامه دیگر، فقط گزینه «افزودن و باز کردن» وجود دارد (بازکردن بدون ذخیره پشتیبانی نمی‌شود).
- متن‌های رابط داخل کد Kotlin نوشته شده‌اند (نه `strings.xml`)؛ ترجمه به زبان دیگر نیاز به بازنویسی دارد.
